# C-CA-EC-2C

EtherCAT 转 CAN 协议转换模块：让存量 CAN 设备接入 EtherCAT 新总线产线，解决「新总线上位系统对接老 CAN 设备」的现场痛点。

> 状态：规划中｜文档更新：2026-10-27｜骨架文档：功能与参数以定型为准，未定型处标注 TBD

- 产品线：协议转换与工具（C）
- 产品编码：C-CA-EC-2C（C=协议转换与工具线，CA=转 CAN，EC=EtherCAT 侧，2C=2 路 CAN 规格码）
- 适用客户：产线集成商、设备厂（现场有存量 CAN 设备）

## 功能特性

| 1 | EtherCAT <-> CAN 双向映射 | 透传/对象映射 | 已规划 |
| 2 | TBD | CAN 通道数（编码按 2 路规划）、组态方式 | 待定义 |

应用场景：产线集成商、设备厂现场有存量 CAN 设备的改造。
